# 熊雷 Leo Xiong 的个人主页

基于真实简历的个人作品集，展示电子硬件、嵌入式控制、测试与 AI 辅助开发经历。

- 线上地址：https://xionglei323-hub.github.io/
- 首页：`index.html`
- 样式：`assets/style.css`
- 交互与项目详情：`assets/app.js`
- 原 GBK 汉字编码工具：`tools/gbk/index.html`（保留原内容）

## 维护

纯静态 HTML / CSS / JavaScript，无依赖和构建步骤。GitHub Pages 从 `main` 分支根目录发布。

编辑首页文字时同步检查项目详情；项目进度更新在 HTML 的状态标签及 JavaScript 的详情数据两处维护。图片与示意图只用于呈现个人身份和工程主题，不表示产品实物。

首页包含移动导航、项目筛选、详情弹窗、邮箱复制和打印样式。打印功能可通过浏览器“另存为 PDF”导出。
